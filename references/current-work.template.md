needed or requested, including a single task outside a repository; reuse an
equivalent existing surface. Remove irrelevant fields rather than create more
documents. For several outcomes, repeat only their distinct state/next step.

message. On continuation, read this first and verify minimum live state.

tasks, deployments, or previously stopped work.
